### API Endpoints
```
POST   /api/shorten              → Create short URL
GET    /:shortCode              → Redirect to original
GET    /api/stats/:shortCode    → View statistics
GET    /api/urls                → List all URLs
DELETE /api/urls/:shortCode     → Delete URL
```

## ❓ Frequently Asked Questions

**Q: Why does it take 15 seconds to load?**
A: Free tier spins down after inactivity. Normal behavior.

**Q: Can I use my own domain?**
A: Yes! See DEPLOYMENT.md for custom domain setup.

**Q: Is my data safe?**
A: Data is stored locally on the server. No external services.

**Q: Can I add authentication?**

**Q: Can I change the short code format?**
